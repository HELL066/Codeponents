## Motion and graceful fallback

Motion is used to explain state changes, such as a value changing or a row entering. `MotionConfig` in `src/main.tsx` respects the system reduced-motion setting; components that use Motion also account for reduced motion where needed. Torph is reserved for changing text and numbers, not decorative movement. Skullet is used for loading placeholders that match the shape of their content.

`ShaderCanvas` is an optional project-owned WebGL surface. It is not required by other components, observes reduced motion, pauses when hidden or offscreen, and keeps a CSS fallback when WebGL is unavailable. Consumers can omit it entirely.

## Updating dependencies

Event previews use Google Calendar’s event-template URL and open the selected event for the user to save.

Add a dependency only when a component uses it and its interaction is meaningfully better than a small local implementation. Keep the component's public API in `src/components/ui/`, expose it from `src/components/ui/index.ts`, and document any new runtime dependency here. Components are source-distributed through the versioned shadcn registry built to `public/r/v1`; no npm package or public registry host is configured.
